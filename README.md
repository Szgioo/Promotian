# Promotian - Marketplace Regional

## Descripción del Proyecto
Promotian es una plataforma web creada para conectar a compradores y vendedores de manera local. Funciona como un mercado digital donde los usuarios pueden ofrecer y encontrar productos fácilmente. El objetivo principal es impulsar el comercio en regiones específicas, asegurando que la plataforma sea rápida, segura y que brinde una excelente experiencia tanto a los negocios como a los clientes.

## ¿Cómo funciona internamente?
Para asegurar que la página funcione rápido y nunca deje de dar servicio, el proyecto organiza la información de una manera muy eficiente:
* El sistema separa la información de los usuarios dependiendo de su ubicación geográfica (abarcando zonas como Chilchotla y Quimixtlán).
* Al mantener los datos divididos por región, las búsquedas y la carga de la página se vuelven mucho más ágiles.
* Las conexiones a la base de datos están programadas bajo un estándar de seguridad que protege la información de las personas.

## Características Principales
* Interfaz pensada en facilitar la compra y venta de artículos locales.
* Sistema de usuarios separado de forma inteligente para no saturar la página.
* Alta disponibilidad y tolerancia a errores gracias a su diseño de múltiples servidores.
* Diseño ligero y fácil de navegar.

## Tecnologías Utilizadas
* Programación del servidor y lógica del sistema: PHP.
* Almacenamiento y gestión de datos: MySQL.
* Estructura, estilos y dinamismo visual: HTML, CSS y JavaScript.

## Pasos para la Instalación en Entorno Local
* Descargar todos los archivos de este repositorio en tu computadora.
* Mover la carpeta del proyecto dentro del directorio principal de tu servidor local (por ejemplo, la carpeta `htdocs` si utilizas un programa como XAMPP).
* Encender los servicios de servidor web y base de datos.
* Abrir el administrador de base de datos y crear los espacios necesarios para alojar la información de cada región.
* Cargar los archivos de respaldo incluidos en el proyecto para construir las tablas de información.
* Abrir los archivos de configuración en el código y actualizar el nombre de usuario y contraseña para que coincidan con los de tu computadora.
* Abrir tu navegador web de preferencia, escribir la ruta local del proyecto y comenzar a utilizar la plataforma.
